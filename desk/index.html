    How to read this

    Edge is how much more often a strategy's picks moved the right way than the market's own base rate for that day. It is not a return. For the lab's current blended score, the average move of its picks after Indian trading costs was slightly negative in the train years (between −0.12 and −0.54 percentage points), so a hit-rate edge is a research finding, not a claim about money made.

    Why there is a correction. The lab tried many variants. Run enough of them and some look good by luck. The joint test (Hansen SPA), the stepwise test (Romano-Wolf StepM) and the model confidence set (MCS) ask whether anything is left once the number of tries is accounted for. Intervals come from a block bootstrap over dates, so days that move together are not counted as independent.

    Limits. Train years only, so none of the lab's strategy results here is validated on unseen data yet. The weekly result is read from the lab's evidence file each time. That file is rebuilt by the lab's own workflow and can lag behind its newest experiments, which are not counted here until the next successful build. This page reads the lab's file each time.
